# Система выявления инцидентов безопасности Windows

Программа мониторинга журналов событий Windows и выявления инцидентов
информационной безопасности на основе настраиваемых правил.

## Требования

- Windows 10 / 11 / Server 2016+
- Python 3.8 или выше
- Права администратора (для чтения журнала Security)
- Библиотека pywin32

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

Откройте терминал **от имени администратора** и выполните:

```bash
python main.py
```

Без прав администратора программа запустится, но журнал Security будет
недоступен — будут читаться только System и PowerShell.

## Использование

1. Нажмите **«Запустить»** — начнётся мониторинг с интервалом 30 секунд.
2. Выявленные инциденты появятся в таблице.
3. Фильтруйте по критичности через выпадающий список.
4. Кнопки **«Экспорт HTML»** и **«Экспорт CSV»** сохраняют отчёт в папке `reports/`.
5. Кнопка **«Статистика»** показывает количество инцидентов по уровням.

## Настройка правил

Правила хранятся в `rules.json`. Можно добавлять свои правила, изменяя
файл, затем перезапустить программу.
